# Contributing Guide

Thank you for improving this repository. All contributions are welcome — corrections, new documents, and structural improvements.

## Ground Rules

1. **Solve a real problem** — every new document must address a named, production-grade challenge. No toy examples.
2. **Be specific** — include a decision matrix, formula, diagram, or copy-pasteable template.
3. **Cite sources** — if you reference data, benchmarks, or tools, link to the source.
4. **Set a Last Verified date** — include `> **Last Verified**: Month YYYY` in every document header.
5. **English only** — all Markdown content must be in English for global developer accessibility.

## How to Submit

1. Fork this repository
2. Create a branch: `git checkout -b feat/your-document-name`
3. Write your document in the appropriate subdirectory
4. Open a Pull Request using the PR template
5. A maintainer will review within 7 business days

## What Gets Rejected

- Abstract theory without actionable content
- Content that duplicates what's already here
- Unverified claims without cited evidence
- AI-generated content that has not been manually reviewed and validated

## Code of Conduct

By contributing, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).
