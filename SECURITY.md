# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository's content, tooling, or referenced configurations, please **do not open a public GitHub Issue**.

Instead, send a private email to: **security@iszgroup.com**

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (optional)

We will acknowledge receipt within 48 hours and aim to publish a fix or advisory within 14 days.

## Scope

This policy covers:
- Security flaws in example configurations published in this repository
- Vulnerabilities in any CI/automation scripts

This policy does **not** cover:
- Third-party tools or services referenced by links
- General vulnerabilities in upstream libraries
